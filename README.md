# 图片批量裁切工具

图片处理桌面工具，支持 Windows 和 macOS。提供批量尺寸转换、宫格裁切，以及京东详情页拼接与分段导出。

从 V1.6 起改用 Tauri 2 + Rust 重写，不再依赖 .NET 运行环境，安装包只有几 MB。

## 功能

- 拖入多张图片，批量转换为 1440 方图、1440 长图、800 方图或商品长图。保持原图比例，用白色背景补齐目标尺寸，输出 JPG。
- 图片裁切：支持自动识别、四角乱切、四宫格拆分和九宫格拆分。自动识别会检测 1/2、1/3、2/3 分界线；未识别为宫格时按四角乱切处理。
- 裁切列表显示每张图片的识别模式，可以逐张修改；右侧切换模式会同步到全部图片。
- 图片裁切支持快速模式：拖入新图片后自动开始处理。可以保存到原图目录，也可以指定文件夹。
- 京东详情页裁切：按列表顺序纵向拼接，统一宽度后预览。每次拖入的一批图片按文件名排序，再追加到列表末尾，不会打乱已调整好的顺序。
- 超长图预览只加载可见区域附近的图片，并在后台生成缩略图缓存，降低大图预览的内存占用与滚动卡顿。支持 `Ctrl + 滚轮`（macOS 也可用 `⌘ + 滚轮` 或触控板捏合）缩放，调整顺序和缩放时直接复用已有缩略图。
- 支持多选图片整体上移、下移，按 `Delete` 删除选中项。
- 京东详情页输出宽度固定为 790 像素，每 1500 像素切一张，保存为 `京东详情-001.jpg` 等高质量 JPG。
- 三个功能页在处理时显示实时进度条（当前阶段、百分比、正在处理的文件和张数），处理期间界面保持可操作。
- 三个功能页都有处理日志，切换页面后仍可查看处理状态。
- 支持深色与浅色主题。

## 下载与安装

请从 [Releases](https://github.com/byttao/PigResizeF/releases) 下载最新版本。

### Windows

需要 Windows 10 或更高版本。程序依赖系统自带的 WebView2；极少数缺少 WebView2 的电脑，安装程序会自动下载。

- **安装版**：`PigResize_<版本>_windows_x64-setup.exe`，双击按提示安装。
- **便携版**：`PigResize_<版本>_windows_x64_portable.zip`，解压后直接运行 `PigResize.exe`。

如果 Windows SmartScreen 提示“已保护你的电脑”，点击“更多信息”，再点“仍要运行”。

### macOS

需要 macOS 11 或更高版本，同时支持 Intel 和 Apple 芯片。

应用没有经过 Apple 公证，下载后直接双击会被系统拦截，所以发布包里附带了安装脚本：

1. 下载 `PigResize_<版本>_macos_universal.zip` 并解压，得到“图片批量裁切工具”文件夹，里面有应用和 `安装.command`。
2. 打开“终端”，输入 `bash `（`bash` 后面有一个空格），把 `安装.command` 拖进终端窗口，按回车。
3. 脚本会把应用复制到“应用程序”文件夹并解除系统拦截，完成后自动打开。之后可以像普通应用一样从启动台或“应用程序”中打开。

升级时，按同样的步骤运行新版本的安装脚本即可覆盖旧版。

也可以手动安装：把应用拖到“应用程序”文件夹，然后在终端执行：

```bash
xattr -dr com.apple.quarantine "/Applications/图片批量裁切工具.app"
```

## 使用方式

### 图片转换

1. 在“图片转换”页拖入图片，或点击“选择图片”。
2. 选择转换样式。
3. 点击“转换”，结果保存到原图所在目录，文件名形如 `原图名称_1440f.jpg`。

### 图片裁切

1. 在“图片裁切”页拖入图片。默认“自动识别”会判断为单图、四宫格或九宫格，也可以手动选择裁切模式。
2. 四角乱切输出 `原图名称-乱切1.jpg` 至 `原图名称-乱切4.jpg`，每张固定为 1440x1920。
3. 四宫格、九宫格输出从 `原图名称-拆分1.jpg` 开始的 JPG 图片。
4. 默认保存到各原图目录；勾选“自定义保存路径”可以统一指定保存文件夹。勾选“快速模式”后，每次拖入的新图片会自动裁切。

### 京东详情页裁切

1. 在“京东详情页裁切”页拖入图片。每次新拖入的图片按文件名排序，追加到现有列表底部。
2. 选中一张或多张图片，用“上移”“下移”调整顺序；按 `Delete` 删除选中项。
3. 点击“拼接预览”检查整体顺序。预览区域可滚动，按住 `Ctrl` 滚动鼠标滚轮可缩放，也可以用右上角的按钮缩放或“适应宽度”。
4. 点击“输出”。图片保存到列表第一张图片所在目录，完成后列表自动清空。

## 本地构建

需要 Node.js 20.19+ 和 Rust 稳定版工具链。

```bash
cd tauri-app
npm install
npm run tauri build
```

开发说明见 [tauri-app/README.md](tauri-app/README.md)。旧版 .NET WinForms 源码仍保留在 `PigResizeF/` 目录中。
