# 图片批量裁切工具

Windows 图片处理桌面工具，支持常规批量裁切，以及京东详情页图片拼接预览与分段导出。

## 功能

- 拖入多张图片，批量转换为 1440 方图、1440 长图、800 方图或商品长图。
- 保持原图比例并以白色背景补齐目标尺寸，输出 JPG 图片。
- 京东详情页裁切：将图片按列表顺序纵向拼接，统一宽度后预览。
- 超长图预览采用可见区域渲染与后台缩略图缓存，支持鼠标滚轮滚动和 `Ctrl + 滚轮` 缩放。
- 京东详情页图片每次拖入的批次按文件名排序后追加到列表末尾，不影响已调整的顺序。
- 支持多选图片整体上移、下移，按 `Delete` 删除选中图片。
- 京东详情页输出宽度固定为 790 像素，每 1500 像素裁切一张，保存为 `京东详情-001.jpg` 等高质量 JPG 文件。
- 启动时检查 GitHub 最新 Release，发现更高版本时提示查看更新。

## 运行环境

- Windows 10 或更高版本。
- [.NET 8 Windows Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)。

发布压缩包不包含 .NET Runtime 安装包；首次运行前请确认目标电脑已安装兼容运行环境。

## 使用方式

### 常规裁切

1. 在“图片裁切”页拖入图片。
2. 选择转换样式。
3. 点击“转换”，结果将保存到原图片目录。

### 京东详情页裁切

1. 在“京东详情页裁切”页拖入图片。每次新增拖入的图片会按文件名排序，并追加到现有列表底部。
2. 选中一张或多张图片，使用“上移”“下移”调整顺序；按 `Delete` 删除选中项。
3. 点击“拼接预览”检查整体顺序。预览区域可滚动，按住 `Ctrl` 滚动鼠标滚轮可缩放。
4. 点击“输出”。图片会保存至列表第一张图片所在目录；完成提示关闭后列表会自动清空。

## 下载

请从 [Releases](https://github.com/byttao/PigResizeF/releases) 下载最新版本。解压后直接运行 `PigResizeF.exe`。

## 本地构建

```powershell
dotnet build PigResizeF.sln -c Release
```

项目基于 .NET 8 Windows Forms，使用 [SixLabors.ImageSharp](https://github.com/SixLabors/ImageSharp) 处理图片。
