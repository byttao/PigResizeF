# 图片批量裁切工具 v1.6.3

基于 Tauri 2 + React + TypeScript + Rust 构建的桌面应用，用于电商图片的批量尺寸转换、宫格裁切，以及京东详情页拼接与分段导出。支持 Windows 和 macOS。

从 V1.6 起由 .NET WinForms 改用 Tauri 2 + Rust 重写，不再依赖 .NET 运行环境，安装包只有几 MB。

## ✨ 功能特性

### 📐 图片转换
- 预设尺寸：1440 方图（1440x1440）、1440 长图（1440x1920）、800 方图（800x800）、商品长图（1440x2160）
- 保持原图比例，白色背景补齐到目标尺寸，输出 JPG
- 支持 JPG、PNG、BMP、GIF，按 EXIF 方向自动转正
- 部分失败时，成功的移出列表，失败的留在列表中标红，可直接重试

### ✂️ 图片裁切
- **自动识别**：检测 1/2、1/3、2/3 处的分界线，判断为四宫格、九宫格或单图
- **四角乱切**：在原图 85% 范围内取最大 3:4 区域，锚定四个角，输出 4 张 1440x1920
- **四宫格 / 九宫格拆分**：按整数边界切分，不丢像素
- 列表逐张显示识别模式，可单独修改；右侧切换模式会同步到全部图片
- 快速模式：拖入新图片后立即开始裁切
- 默认保存到原图目录，也可以统一指定保存文件夹

### 🧩 京东详情页
- 按列表顺序纵向拼接，统一为 790 像素宽，每 1500 像素切一张，输出 `京东详情-001.jpg` 等
- 每次拖入的一批图片按文件名排序后追加到列表末尾，不打乱已调整好的顺序
- 多选图片整体上移、下移，`Delete` 删除选中项
- 拼接预览只加载可见区域附近的图片，后台生成缩略图缓存；支持 `Ctrl + 滚轮`（macOS 也可用 `⌘ + 滚轮`、触控板捏合）和按钮缩放

### 🖥️ 通用
- 实时进度条：当前阶段、百分比、正在处理的文件和张数，处理期间界面可操作
- 三个功能页各有处理日志；切换页签不会清空列表、日志和滚动位置
- 7 套主题 + 深色模式，选择会被记住
- 启动时检查 GitHub 新版本，有更新时提示是否打开发布页；网络不可用时不影响使用

## 📥 下载与安装

请从 [Releases](https://github.com/byttao/PigResizeF/releases) 下载最新版本。

### Windows

需要 Windows 10 或更高版本。程序依赖系统自带的 WebView2；极少数缺少 WebView2 的电脑，安装程序会自动下载。

- **安装版**：`PigResize_<版本>_windows_x64-setup.exe`，双击按提示安装。
- **便携版**：`PigResize_<版本>_windows_x64_portable.zip`，解压后直接运行 `PigResize.exe`。

如果 Windows SmartScreen 提示“已保护你的电脑”，点击“更多信息”，再点“仍要运行”。

### macOS

需要 macOS 11 或更高版本，同时支持 Intel 和 Apple 芯片。

应用没有经过 Apple 公证，下载后直接双击会被系统拦截，所以发布包里附带了安装脚本：

1. 下载 `PigResize_<版本>_macos_universal.zip` 并解压，得到“图片批量裁切工具”文件夹，里面有应用和 `安装.command`。
2. 打开“终端”，输入 `bash `（`bash` 后面有一个空格），把 `安装.command` 拖进终端窗口，按回车。
3. 脚本会把应用复制到“应用程序”文件夹并解除系统拦截，完成后自动打开。之后可以像普通应用一样从启动台或“应用程序”中打开。

升级时，按同样的步骤运行新版本的安装脚本即可覆盖旧版。

也可以手动安装：把应用拖到“应用程序”文件夹，然后在终端执行：

```bash
xattr -dr com.apple.quarantine "/Applications/图片批量裁切工具.app"
```

## 📖 使用方式

### 图片转换

1. 在“图片转换”页拖入图片，或点击拖拽区选择文件。
2. 在右侧“转换样式”中选择目标尺寸。
3. 点击“开始转换”，结果保存到原图所在目录，文件名形如 `原图名称_1440f.jpg`。

### 图片裁切

1. 在“图片裁切”页拖入图片。默认“自动识别”会判断为单图、四宫格或九宫格，也可以手动选择裁切模式。
2. 四角乱切输出 `原图名称-乱切1.jpg` 至 `原图名称-乱切4.jpg`；四宫格、九宫格输出从 `原图名称-拆分1.jpg` 开始的图片。
3. 默认保存到各原图目录；勾选“自定义保存路径”可以统一指定保存文件夹。勾选“快速模式：拖入后立即开始”后，每次拖入的新图片会自动裁切。
4. 点击“开始裁切”。

### 京东详情页

1. 在“京东详情页”拖入图片。每次新拖入的图片按文件名排序，追加到现有列表底部。
2. 选中一张或多张图片（`Shift` 连选、`Ctrl` / `⌘` 多选），用“上移”“下移”调整顺序，按 `Delete` 删除选中项。
3. 点击“拼接预览”检查整体顺序，可缩放或“适应宽度”。
4. 点击“输出”。图片保存到列表第一张图片所在目录，完成后列表自动清空。

## 🚀 技术栈

### 前端
- **框架**：React 19 + TypeScript
- **构建工具**：Vite 8
- **界面**：[ui-kit](https://github.com/byttao/ui-kit)（基于 Ant Design 6）+ Tailwind CSS
- **桌面框架**：Tauri 2

### 后端
- **语言**：Rust
- **图片解码 / 编码**：image crate（0.25）
- **图片缩放**：fast_image_resize（Lanczos3，SIMD 加速）
- **并发处理**：rayon（批处理最多同时 4 张）
- **更新检测**：reqwest

## 🛠️ 开发

### 开发环境要求
- Node.js 20.19+ 或 22.12+（Vite 8 要求）
- Rust 1.90+
- Windows：WebView2（Windows 10/11 一般已自带）；macOS：Xcode Command Line Tools

### 常用命令

```bash
cd tauri-app
npm install

# 启动开发版
npm run tauri dev

# 构建当前平台的安装包
npm run tauri build
```

开发模式下依赖库未开启编译优化，出图速度会比正式版慢很多。需要测速度时用 `npm run tauri -- dev --release`。

更多开发说明（macOS 通用版打包、进度事件、详情页预览实现）见 [tauri-app/README.md](tauri-app/README.md)。

### 发布

推送 `v*` 标签后，GitHub Actions（[release.yml](.github/workflows/release.yml)）会编译 Windows 安装版、Windows 便携版和 macOS 通用版，并上传到 Release 草稿。

## 📊 性能对比

在 Apple M4 上实测，同一批图片、同样的输出参数（单位：秒）：

| 场景 | .NET 版（ImageSharp） | V1.6.2 | V1.6.3 |
|------|:---:|:---:|:---:|
| 图片转换，10 张 896x1200 PNG | 0.16 | 8.3 | 0.17 |
| 四角乱切，10 张 896x1200 PNG | 2.5 | 68.2 | 0.59 |
| 九宫格，10 张 896x1200 PNG | 0.37 | 10.8 | 0.09 |
| 图片转换，12 张约 3000x4000 JPG | 0.50 | 15.3 | 0.29 |
| 四角乱切，12 张约 3000x4000 JPG | 5.5 | 135.0 | 0.93 |
| 九宫格，12 张约 3000x4000 JPG | 2.9 | 90.5 | 0.50 |

V1.6.2 慢是因为保存 JPG 时没有缓冲写入，V1.6.3 已修复，并加入多图并发和 SIMD 缩放。

| 安装包 | .NET 版 V1.5 | V1.6.3 |
|------|:---:|:---:|
| Windows | 0.9 MB，需另装 .NET 8 桌面运行时 | 安装版 2.6 MB / 便携版 3.4 MB，无需额外运行时 |
| macOS | 不支持 | 6.8 MB（Intel + Apple 芯片通用） |

## 📝 更新日志

### V1.6.3（2026-11-03）
- 出图速度大幅提升：修复保存 JPG 时未缓冲写入导致的慢速问题，图片转换、图片裁切、京东详情页输出快 10～40 倍。
- 图片转换、图片裁切同时处理多张图片（最多 4 张），缩放改用 SIMD 加速，大图四角乱切再快约一倍。
- 带透明通道的 PNG 在图片裁切中透明部分改为白底，与图片转换、京东详情页一致。
- 启动时自动检查 GitHub 新版本，有更新时提示是否打开发布页；网络不可用时不影响使用。

### V1.6.2（2026-10-27）
- 界面改用 [ui-kit 1.2.0](https://github.com/byttao/ui-kit)（Ant Design 6）：按钮、单选、下拉、表格、提示等控件统一为 Ant Design 组件。
- 图片转换、图片裁切部分失败时，处理成功的图片移出列表，失败的图片留在列表中并标红（带失败标记），可调整后直接重试；快速模式下未参与本次处理的图片不再被一并清空。
- 默认外观为「森翠雅韵」主题：浅色、浅色侧栏、毛玻璃卡片；侧栏底部可切换 7 套主题和深色模式，选择会被记住。
- 切换功能页签不再清空图片列表和日志，切回来时内容与滚动位置都在；拖入的图片只进入当前页签。
- 图片裁切新增「清空列表」按钮。
- 软件图标恢复为原 C# 版本的图片图标。
- 正文 12px、全部文字与背景对比度达到 WCAG AA（4.5:1），状态信息带图标，不只靠颜色区分。
- 图片列表、裁切表格、日志面板与侧栏统一样式；拖拽区在有图片后自动收成一行，把空间让给列表。
- 系统开启「减弱动态效果」时自动关闭界面动效。

### V1.6.1（2026-10-25）
- 京东详情页预览改为后台缩略图缓存，只加载可见区域附近的图片，降低大图预览的内存占用与滚动卡顿。
- 预览支持 `Ctrl + 滚轮`、触控板捏合和按钮缩放，放大后可按住鼠标拖动查看左右细节。
- 调整顺序、缩放、重新预览时直接复用已有缩略图。

### V1.6（2026-10-25）

- 图片转换、图片裁切、京东详情页裁切新增实时进度条，显示当前阶段、百分比和正在处理的文件。
- 图片处理改到后台线程执行，处理大图时界面不再卡顿。

```

└── tauri-app/
    ├── src/                       # React 前端

    │   ├── components/
    │   │   ├── ImageConvertTab.tsx    # 图片转换

    │   │   ├── JdDetailsTab.tsx       # 京东详情页
    │   │   └── JdPreview.tsx          # 详情页拼接预览（虚拟滚动、缩略图、缩放）
    │   ├── lib/                   # 图片格式等工具
    │   ├── types/                 # 与 Rust 端对应的类型
    │   └── ui-kit/                # 从 byttao/ui-kit 拷入的界面组件库
    ├── src-tauri/                 # Rust 后端

    │   ├── Cargo.toml
    │   └── tauri.conf.json
    ├── scripts/                   # macOS 打包与安装脚本
    └── package.json
```
